# HeavyRain_BDMD
Workflow Agent Infrastructure

## Getting Started

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
2. Configure your Google Gemini API key in `.env`:
   ```env
   GOOGLE_API_KEY=your_gemini_api_key_here
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

## Development & Customizations

This workspace is integrated with Antigravity, Git, and the GitHub CLI (`gh`).
